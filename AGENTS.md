## Setup commands
Using the following command:
```bash
ls -ltah ~/.config
```

check the users `~/.config/` directory to see what they have symlinked back to the directory this file lives in. 

## Code style
This is a config only repository. Scripts should be kept minimial, and apply to a single area of focus.
- use bash for interfacing with linux binaries
- update `zsh/alias.zsh` with any helper functions that may be requested.
